# Premium Next.js 15 Dark Portfolio - I. Nikhil Reddy

A modern, high-performance, dark-themed personal portfolio website built with **Next.js 15 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lucide Icons**.

Designed to showcase the academic background, technical skills, machine learning projects, certifications, and GitHub activity of **Idamakanti Nikhil Reddy**, a final-year B.Tech CSE (AI & ML) student at Vel Tech University.

---

## 🌟 Key Features

- **Dark Obsidian Aesthetics**: Customized dark theme (`#030712`) with vibrant electric blue (`#3b82f6`) and purple (`#8b5cf6`) gradient accents.
- **Glassmorphism UI**: Glass cards with dynamic backdrop blur (`backdrop-blur-xl`), glow borders, and subtle radial mesh overlays.
- **Hero Section**: Animated typewriter effect highlighting key developer roles, status badge, call-to-action buttons, and smooth scroll indicator.
- **Particle & Cursor Effects**: Interactive HTML5 particle canvas background reacting to mouse movement with custom cursor radial glow.
- **Academic Timeline**: Interactive vertical education timeline detailing B.Tech (AI & ML) at Vel Tech University (8.01 GPA), Sri Chaitanya JR College, and Secondary Education (100% distinction).
- **Categorized Skill Cards**: Animated progress bars categorized under Programming, Web Development, Machine Learning & AI, and Databases & Tools.
- **Filterable Projects Showcase**: Interactive category filters, project cards with tech stack tag pills, live demo links, GitHub links, and detail modal overlay.
- **Verified Certifications & Achievements**: Industry certifications from Cisco CCNA 1, Infosys Springboard ML & Software Testing, along with IEEE research paper distinction.
- **Resume Section**: Interactive resume card with direct download trigger for `public/resume.pdf`.
- **GitHub Stats Integration**: Live stats card, contribution activity mesh visualizer, and top language distribution breakdown.
- **Interactive Contact Form**: Client-side validated contact form connected to a Next.js API Route with success feedback and confetti celebration.
- **Vercel & SEO Ready**: Dynamic metadata, OpenGraph tags, dynamic `sitemap.xml`, `robots.txt`, custom SVG favicon, and zero build errors.

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18.17 or higher) and **npm** installed on your system.

### 1. Installation

```bash
npm install
```

### 2. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your web browser to view the portfolio.

### 3. Production Build & Test

```bash
npm run build
npm run start
```

---

## 🌐 Deploying to Vercel

1. Push your repository to GitHub.
2. Sign in to [Vercel](https://vercel.com/) and click **New Project**.
3. Import your GitHub repository (`nikhil-reddy-portfolio`).
4. Keep framework preset as **Next.js**.
5. Click **Deploy**. Vercel will automatically build and publish your site with SSL and global CDN optimization.
